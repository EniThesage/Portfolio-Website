## ✨ Features

- Fully responsive design (Mobile, Tablet & Desktop)
- Bootstrap 5 offcanvas mobile navigation
- Featured Projects section with:
  - Live demo links
  - GitHub repository links
- Dedicated About page
- Capabilities (Skills) section
- Experience section
- Contact form integration using Formspree
- Social media links (GitHub, LinkedIn, X, Facebook, WhatsApp)
- Smooth scrolling navigation
- Clean and consistent UI design system

## 📬 Contact Form Setup (Formspree)

The contact form is powered by Formspree.

To use your own Formspree form:

Create an account at https://formspree.io

Create a new form

Replace the action URL inside the form:
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">

This project uses JavaScript fetch() to:

Prevent page reload

Submit form asynchronously

Display a success message dynamically
